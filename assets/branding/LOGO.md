# Hymnals logo

Current master: `hymnals-logo-v1.png`. The existing open hymnbook and musical-note mark was recoloured using the built-in image-generation tool. The supplied crest is only a colour reference and is not packaged or used as the app logo.

The palette uses royal blue #2E3192, red, green #147341 and white. Interface red #D91F2A provides readable controls. Android, iOS and web icons plus native launch images are generated by `tools/build_brand_assets.py`. Android adaptive and web maskable icons include extra safe space. The previous Hymnora master is preserved as historical artwork.

The app display name is Hymnals. Existing application identifiers remain unchanged to preserve installed app data. Studio hosting and backend identifiers remain unchanged.
