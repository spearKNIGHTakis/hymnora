# Studio design specification
Reference: design-concept.png (built-in Image Gen). Cream #FFF8E7 main canvas; navy #183B56 sidebar/buttons; pale blue selection #D6E4EC; border #E5D8BF. Sidebar 230px, editor 390px, main gutters 32px. System sans-serif, 32px heading, 14px controls, 1.5 line height. Lucide line icons. Tables and an editorial drawer; no metric cards. 6px control radii. Primary copy follows the concept: Hymnora Studio, Hymns, Recordings, Review queue, History, Admin, Sign out, Hymn library, Prepare, review and publish your hymnbook., Import catalogue, Add hymn, Edit hymn, Save draft, Send for review.
Necessary states: authenticated login and admin denial; private source-PDF upload and signed preview; publication and proofreading controls; import progress, version restore and timing markers. Source PDFs and catalogue imports are NEVER placed in public site assets. Development preview uses labelled local sample drafts and is removed from production by Vite's DEV condition. Production lists only authenticated backend data. Responsive mobile editor overlays the table; reduced-motion removes transitions. All application controls are native HTML/React.
